# Plan 260508-iy7: dev.js Win+Node20 spawn EINVAL 修复

## Root Cause

`desktop/scripts/dev.js` 的 `spawnPnpm` 调用：

```js
spawn(resolvePnpmCommand(), args, { cwd, env, stdio: "inherit" })
```

`resolvePnpmCommand()` 在 win32 返回 `"pnpm.cmd"`。Node 20+（含 18.20.x、20.12.x 等）合并 CVE-2024-27980 的修复后，**拒绝直接 spawn `.cmd` / `.bat` 文件**，必须 `shell: true`。否则抛 `spawn EINVAL`。

## Fix

`spawnPnpm` 的 options 加 `shell: process.platform === "win32"`。args 全是常量字符串（`"run"` / `"build:main"` / `"exec"` / `"electron"` / `MAIN_ENTRY` 路径），无 shell 注入风险。

## Verify

- `node --check scripts/dev.js` 语法过
- 实际跑 `pnpm dev` 不再 EINVAL（用户回归）
