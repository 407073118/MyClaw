# Quick 260508-fc4 — Plan

## Goal
Day Timeline 加「当前时间」横向指示线，对齐 Apple Calendar / Google Calendar / Sunsama 的「now line」基本预期。仅在用户当前查看的就是「今天」时显示，每分钟更新一次位置；首次渲染时自动滚到当前时间。

## Tasks

### Task 1 — ScheduleTimeline 接入 isToday 与 now-line

**files:**
- desktop/src/renderer/pages/TimeCenterPage.tsx

**action:**
1. 给 `ScheduleTimeline` 加两个 props：`selectedDate: string` 与 `todayDateKey: string`。在调用处（第 312 行附近）传入已存在的 `selectedDate` 和 `todayDateKey`。
2. 组件内派生 `isToday = selectedDate === todayDateKey`。
3. 加 `now` state：
   - 初值：`isToday ? new Date() : null`
   - `useEffect` 仅在 `isToday` 时启动 `setInterval(() => setNow(new Date()), 60_000)`，并在依赖变化或卸载时 `clearInterval`。
   - 切到非今天时清空 `now`。
4. 加 `boardRef = useRef<HTMLDivElement | null>(null)` 挂到 `.timeline-board`。
5. 加 `nowTop` state（number | null），用 `useLayoutEffect` 在 `now`、`isToday`、`entries.length`（行高会随事件变化）变化时重算：
   - 找到 `[data-testid="timeline-hour-${hour}"]`（hour 取 `now` 在当前 timezone 下的本地小时；超过 23 视作 23）。
   - `top = row.offsetTop + (minute / 60) * row.offsetHeight`。
   - 同时若是「首次定位」（用 `didScrollRef` 守卫，仅每次切到 today 时滚一次），调用 `boardRef.current.scrollTop = Math.max(0, top - 160)` 让红线大概落在视口中段。
6. 在 `.timeline-board` 内（`{DAY_HOURS.map(...)}` 旁、`{entries.length === 0 ? ... : null}` 之上）渲染：
   ```tsx
   {isToday && nowTop !== null ? (
     <div
       className="timeline-now-line"
       style={{ top: nowTop }}
       data-testid="timeline-now-line"
       aria-hidden="true"
     >
       <span className="timeline-now-line__dot" />
       <span className="timeline-now-line__label">{formatNowLabel(now, timezone)}</span>
     </div>
   ) : null}
   ```
7. 在文件底部已有的 styled-jsx 风格 CSS 块里追加 `.timeline-now-line` 规则：
   - `position: absolute; left: 64px; right: 0;`（内容列起点对齐 hour 标签右边，与 `.timeline-hour-row` 的 64px label 列匹配）
   - 1px 高、`background: #ef4444`、`box-shadow: 0 0 6px rgba(239, 68, 68, 0.45)`、`pointer-events: none; z-index: 5;`
   - 子节点 `.timeline-now-line__dot`：`position: absolute; left: -4px; top: -3px; width: 7px; height: 7px; border-radius: 50%; background: #ef4444;`
   - 子节点 `.timeline-now-line__label`：`position: absolute; right: 8px; top: -16px; font-size: 11px; font-family: ui-monospace, "SF Mono", Menlo, Consolas, monospace; color: #ef4444;`
8. 加一个本文件内的 `formatNowLabel(now, timezone)` 小工具，用 `Intl.DateTimeFormat` 输出 `HH:mm`。
9. 维持现有 `getLocalHour` 工具（已在文件中）用于取本地小时。

**verify:**
- `pnpm --filter ./desktop run typecheck` 或 desktop 自身 ts 编译命令通过。
- 启动 desktop dev，进入 `TimeCenterPage`：
  - 选中日期是今天时：时间轴上出现红色横线，`HH:mm` 标签在右侧，dot 在左端。
  - 点击「下一天」按钮：红线消失。
  - 回到今天：红线再次出现，且首次回到今天时滚动条已自动调整到红线附近。
  - 等待一分钟（或人工把系统时钟调几分钟）：红线 `top` 重新计算。

**done:**
- 红线 DOM 在今日视图存在并随时间更新；非今日视图无红线；切回今日时滚动条对准红线。

## Out of scope
- 其他视图（events / reminders / jobs 列表页）的当前时间提示。
- 周视图 `WeekTimeline`（不在用户描述范围）。
- 用户拖动时间轴或缩放小时高度等交互。
