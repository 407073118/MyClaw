## 设计理由（参考 Linear / GitHub Desktop / Tower）

桌面专业 app 的密集列表**不靠左侧色条**做状态标识 —— 它们用：
- 状态点（8px dot）或紧凑 badge 在行内承担状态
- hover 才显形的次级操作（不堆 UI）
- 异步操作必须有 loading（spinner + disabled）

3px 左色条更接近 web 卡片审美，塞进密集列表会出现：信息层级被竖线挤压、行节奏被打断。已撤掉。
