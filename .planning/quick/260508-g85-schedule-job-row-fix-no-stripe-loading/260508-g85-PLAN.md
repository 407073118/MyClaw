# Quick 260508-g85 — Plan

## 决策（参考 Linear / GitHub Desktop / Tower / Sentry 行状态做法）

桌面专业 app 的列表行**不靠左侧色条做状态**——它们用：
- 一个稳定网格、信息密度高的行
- 状态用「8px dot + 文字」或紧凑徽章承担
- hover 揭示二级操作
- 异步操作有明显 loading（spinner + disabled）

我之前加的 3px stripe 是 web 卡片审美塞到桌面密集列表，错了。撤掉。

### Task 2 — 修复行内文字与操作按钮重叠

**根因分析：**
- `.list-page-row--job` 网格列：`140px / 1.5fr / 1fr / minmax(220px, auto)`
- 操作列 `auto` 部分允许撑大；3 个按钮（「执行」「暂停/恢复」「删除」）含图标+中文+padding，每个 ~70px，加 gap，实际可超 220px
- 当容器变窄，`auto` 撑住右列、文字列被挤压，但「上次xxx」`.job-row__run` 没设 ellipsis，会溢出到操作区视觉重叠

**action:**
1. 操作按钮：将「执行」与「暂停/恢复」改为图标专用（保留 `title` tooltip 与 `aria-label`，移除 `<span>` 文案），与 IconTrash 一致；让操作列收紧。
   - 实现：去掉 `<ActionIconButton>` children 里的 `<span>执行</span>` 与 `<span>{paused ? '恢复' : '暂停'}</span>`，只剩图标。
   - `.job-action-icon-btn` padding 改 `0 8px`，仍 30px 高，icon-only 时方形感更紧凑。
2. 操作列宽：grid `minmax(220px, auto)` → `minmax(132px, auto)`（3 个 30px 按钮 + 2 个 8px gap = 106px，预留 hover 余量）。
3. 防溢出加 ellipsis：
   - `.job-row__run` 加 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`
   - `.list-page-row__time` 同上保险
4. 网格 col2 加显式 `overflow: hidden`：CSS `.list-page-row > div:not(.job-row__actions) { min-width: 0; overflow: hidden; }`（已有 min-width:0，再加 overflow:hidden 兜底）。

### Task 3 — 执行按钮加 loading 状态

**action:**
1. `ActionIconButton` props 扩展：
   ```ts
   {
     title: string;
     onClick: () => void | Promise<void>;
     variant?: "default" | "danger";
     loading?: boolean;
     disabled?: boolean;
     children: React.ReactNode;
   }
   ```
   渲染：`disabled = loading || disabled`，loading 时 children 替换为 `<IconSpinner />`，按钮加 `is-loading` class。
2. 新增 `IconSpinner` 组件：14x14 SVG `<circle>` 描边 1.6 + `stroke-dasharray`，外层用 CSS `@keyframes` 旋转。
3. ScheduleJobListPage 加 state：
   ```ts
   const [pendingRunIds, setPendingRunIds] = useState<Set<string>>(() => new Set());
   const handleRunClick = async (job) => {
     setPendingRunIds((prev) => new Set(prev).add(job.id));
     try {
       await onRunNow(job);
     } finally {
       setPendingRunIds((prev) => { const next = new Set(prev); next.delete(job.id); return next; });
     }
   };
   ```
4. 执行按钮：`<ActionIconButton title="立即执行" loading={pendingRunIds.has(job.id)} onClick={() => handleRunClick(job)}>...</ActionIconButton>`。
5. CSS：
   - `.job-action-icon-btn[disabled] { opacity: 0.55; cursor: progress; }`
   - `.job-action-icon-btn.is-loading { color: var(--accent-cyan); border-color: rgba(16,163,127,0.32); background: rgba(16,163,127,0.08); }`
   - `.icon-spinner { animation: iconSpin 0.8s linear infinite; }`
   - `@keyframes iconSpin { to { transform: rotate(360deg); } }`
