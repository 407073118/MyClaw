# Quick Plan — Workflow 三层修复（先能跑 / 清 sidebar / 数据样式）

## Goal

让 workflow 从"看起来全坏了"恢复到"能用、不报错、配置项一目了然"：

1. **P0**：1-node start→end 工作流点击运行能跑通、状态显示正确、子工作流节点不再让引擎崩溃
2. **P1**：编辑器右侧 sidebar 只展示引擎真正会读的字段，删除沉默写丢的死配置、修好 conditional edge 编辑
3. **P2**：清死代码、收紧契约、`WorkflowRunPanel` token 化与按钮规范化

## Background

四 agent 调研已完成（详见 quick-task 主 prompt 的 `<diagnosis>` block）。**所有问题已定位到 file:line，不要重新调研。** 本计划的 task 都直接落到具体行号。
