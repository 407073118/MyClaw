<objective>
把 Prompt 类型定时任务从「一个 job 永久绑定一个累积 session」重构为「每次触发新建独立 session（per_run）默认 + 老 job/显式 opt-in 用 shared」。
ExecutionRun 与 ChatSession 1:1 关联，详情页执行记录行可展开内嵌该次会话消息流 + 继续聊天，保留 shared 兼容路径不破坏老 job。

Purpose: 解决三个真实痛点 — 累积上下文 token 越来越贵 / 执行历史与对话脱钩 / 详情页"对话"区在没首次执行前 disabled 输入框造成 UX 割裂。
Output: 数据模型新增 sessionMode + ExecutionRun.sessionId + ChatSession.associatedScheduleJobId；executor 双分支；调度器透传；store 迁移钩子；详情页 UI 重构；4 个测试文件联动更新。
</objective>
